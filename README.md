# 提瓦特剧情档案

一个帮助你梳理《原神》任务顺序、查找剧情实录、记录观看进度的任务地图。

**[打开任务地图](https://zyx20180209.github.io/teyvatarchive-front/)**

无需安装或登录，电脑和手机浏览器均可使用。适合想按顺序补剧情、回顾已完成任务，或寻找错过的活动剧情的旅行者。

## 可以做什么

- **查看任务关系**：以版本为纵轴，通过流程图查看主线、角色任务、世界任务和活动之间已整理的先后关系。
- **查找具体章节**：搜索任务名、角色或系列名。森林书等系列按独立词条展示，卡片角落标明所属系列。
- **寻找剧情实录**：打开任务详情，使用已有的视频链接；部分链接可直接定位到 B 站分 P，也可继续在 B 站或 YouTube 搜索。
- **记录个人进度**：勾选“已看过 / 已完成”，筛选尚未观看或完成的任务。

## 如何使用

1. **找到感兴趣的任务**
   在搜索框输入任务、角色或系列名称，也可以通过版本、任务类型、地区和进度筛选。
2. **查看任务详情**
   点击任务卡片，查看可用的剧情简介、视频链接和前序任务。点击前序任务可跳转；有内部流程的词条可以展开查看。
3. **观看剧情**
   点击“观看实录”中的链接前往视频平台。没有合适的固定链接时，使用下方的视频搜索入口。
4. **标记进度**
   在卡片上勾选“已看过 / 已完成”。之后选择“未看 / 未完成”，即可继续查找尚未补完的内容。

地图可拖动空白处平移，也可使用滚轮或触控板滚动。通过缩放滑杆、`Ctrl/⌘ + 滚轮` 调整大小；支持的浏览器中也可以使用触控板双指捏合。“全图”用于查看整体分布，“回到起点”返回地图开头。右上角按钮可切换明暗主题。

手机上点击任务后，详情位于任务图下方。

## 如何理解任务图

卡片颜色用于区分任务类型：

| 颜色 | 任务类型 |
| --- | --- |
| 金色 | 魔神任务 |
| 紫色 | 角色传说、邀约事件、部族纪闻 |
| 蓝色 | 世界任务 |
| 绿色 | 活动及其他任务 |

排序优先参考已确认的剧情顺序和前置关系，再参考实装版本及已知日期。前序任务在上，后续任务在下；一个任务可以连接多个前序。

**同一行不代表剧情一定同时发生，没有连线也不代表没有前置。** 部分关系仍待核对。连线包含剧情先后与解锁前置两种含义，具体游戏内接取条件请结合任务详情和来源资料判断。系列内某一步的前置，也不一定要求完成整个系列。

## 数据来源

- **[米游社·观测枢任务图鉴](https://baike.mihoyo.com/ys/obc/channel/map/189/43)**：任务名称、分类、版本、章节与前后续关系的主要来源。内容包含社区整理与编辑。
- **[原神 BWIKI](https://wiki.biligame.com/ys/首页)**：补充核对魔神任务章幕、活动与版本信息，例如[魔神任务](https://wiki.biligame.com/ys/魔神任务)和[活动一览](https://wiki.biligame.com/ys/活动一览)。
- **《原神》官方更新公告**：用于核对部分版本的更新日期。版本更新日不一定等于每个任务的实际开放日。
- **B 站及 YouTube 的公开视频信息**：根据标题、简介、合集、分 P 等信息查找剧情实录。当前固定推荐主要来自 B 站，两个平台均保留搜索入口。

本项目是非官方的任务与视频索引。数据仍在补充和校对，不保证已经覆盖游戏中的全部任务、隐藏任务、每日委托系列或所有活动，也不把百科目录顺序直接当作剧情顺序。

视频匹配仅依据公开文字信息，未逐一观看核验。整理时会区分剧情实录与剧情解析、考据、混剪等内容，但已有链接仍可能省略战斗、跑图或部分流程。分 P 链接是观看入口，后续内容可能位于相邻分 P。视频由原作者在对应平台提供，本项目不托管视频。

## 进度保存与问题反馈

完成勾选保存在**当前浏览器**中，刷新页面通常会保留；不同用户互不影响。进度不会上传到游戏账号，也不会自动跨设备、跨浏览器或跨域名同步。清除网站数据或使用无痕模式可能导致进度丢失。

如果发现任务遗漏、顺序错误、分类不准确或视频失效，欢迎通过 [GitHub Issues](https://github.com/zyx20180209/teyvatarchive-front/issues) 反馈。请尽量提供任务完整名称、相关版本和米游社/BWIKI依据；推荐视频时，可附上对应分 P 和标题，方便核对。

感谢米游社、BWIKI 的社区编辑，以及分享剧情实录的视频创作者。
